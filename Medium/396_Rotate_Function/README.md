## 396_Rotate_Function

Rotate Function:
    1. Calculate the total sum of the array and the initial value of F(0).
    2. Use the relationship between F(k) and F(k-1) to calculate F(k) iteratively for k = 1 to n-1.
    3. Keep track of the maximum value of F(k) during the iterations.
    
Time Complexity: O(n)
Space Complexity: O(1)
