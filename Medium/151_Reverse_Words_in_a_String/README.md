## 🧠 Approach
- Trim leading and trailing spaces from the input string
- Split the trimmed string into words using spaces as separators
- Reverse the order of the words
- Join the reversed words with single spaces between them


## ⏳ Time Complexity
- O(n), where n is the length of the input string, due to iterating through the string to trim spaces and extract words


## 💾 Space Complexity
- O(n), where n is the length of the input string, due to storing the words in a vector and building the result string
